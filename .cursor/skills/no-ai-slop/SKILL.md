# No AI Slop (Dusk)

Follow the personal `no-ai-slop` skill. For this repo specifically:

- Dusk already chose quiet night chrome and system type — do not reinvent a SaaS kit on top.
- Prefer cover-led composition over hairline/settings-list aesthetics on music surfaces.
- Do not “fix emptiness” with grey boxes, soft pills, or extra divider stacks.
- Before presenting a UI change: remove one accessory and verify it still reads as Dusk, not template dark mode.
